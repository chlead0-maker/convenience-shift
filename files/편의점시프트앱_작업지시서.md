# 편의점 주간 시프트표 — 웹앱 제작 지시서 (Claude Code용)

> 사용법: 새 폴더를 만들고 그 안에서 `claude` 를 실행한 뒤, 아래 내용을 **첫 메시지로 통째로 붙여넣으세요.**
> 함께 받은 `convenience-shift-scheduler.jsx` 파일을 같은 폴더에 넣어두면, UI 참고 자료로 쓸 수 있습니다.

---

## 1. 만들 것

편의점 직원들이 **링크 하나로 공유**해서 함께 보고 수정하는 **주간 시프트(근무) 관리 웹앱**.
직원은 계정 없이 폰에서 링크로 들어와 자기 시프트를 추가·수정할 수 있어야 한다.
같은 표를 여러 명이 동시에 보며, 한 사람이 수정하면 **다른 사람 화면에도 자동 반영(실시간)** 되어야 한다.

같은 폴더의 `convenience-shift-scheduler.jsx` 가 원하는 화면과 기능의 기준이다. 이 디자인과 기능을 최대한 그대로 살리되, 데이터 저장만 진짜 백엔드로 바꾼다.

## 2. 기술 스택

- 프론트엔드: **Vite + React + Tailwind CSS**
- 백엔드/DB: **Supabase** (Postgres + Realtime 구독)
- 배포: **Vercel** 기준으로 안내 (Netlify도 가능)
- 환경변수는 `.env` 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 로 관리하고 `.gitignore` 에 추가

비개발자가 따라 할 수 있게, **Supabase 프로젝트 생성 → 테이블 만들기 → 키 복사 → 배포** 단계를 진행 중에 하나씩 친절히 안내해 줘. 내가 직접 해야 하는 건(웹사이트에서 클릭하는 것 등) 명확히 짚어주고, 코드로 가능한 건 네가 다 작성해 줘.

## 3. 기능 요구사항

- 주간(월~일) 보기, 이전 주 / 다음 주 / 이번 주 이동
- 각 요일 칸에 시프트 카드 추가. 한 카드 정보: **이름 / 시작·종료 시간 / 역할 / 메모**
  - 역할 프리셋: 오픈, 미들, 마감, 계산, 발주, 청소, 물류 (+ 직접 입력 가능)
- 카드를 누르면 수정·삭제
- **누구나 편집 가능** (권한 구분 없음)
- 각 요일에 **특이사항** 표시 (예: 물류 입고, 행사) — 별도 표시로 강조
- 시간대별 색 구분(오전/오후/야간), 직원별 고정 색상
- 하단에 **직원별 주간 근무 횟수·시간 요약**
- 오늘 날짜 강조, 주말 색 구분
- 매장 이름 편집 가능
- 모바일에서 잘 보이도록 반응형 (직원 대부분 폰으로 봄)

## 4. 데이터 모델 (Supabase)

`stores` 테이블이 없는 단순 버전부터 시작한다. 한 매장 = 하나의 앱 인스턴스로 두고, 다음 테이블을 만든다:

- **shifts**
  - `id` (uuid, pk, default gen_random_uuid())
  - `week_start` (date) — 그 주 월요일 날짜
  - `day` (int) — 0=월 … 6=일
  - `name` (text)
  - `start_time` (text) — "HH:MM"
  - `end_time` (text)
  - `role` (text)
  - `memo` (text)
  - `created_at` (timestamptz, default now())
- **special_days**
  - `id` (uuid, pk)
  - `week_start` (date)
  - `day` (int)
  - `note` (text)
  - unique(week_start, day)
- **settings**
  - `key` (text, pk)  — 예: "store_name"
  - `value` (text)

Realtime: shifts, special_days, settings 변경을 구독해서 화면 자동 갱신.

> 보안 메모: 처음엔 빠르게 동작시키기 위해 RLS를 열어두거나 anon 키로 읽기/쓰기 허용으로 시작해도 된다. 단, **나중에 외부에 널리 공개할 경우** 누구나 데이터를 지울 수 있는 위험이 있으니, 그 시점에 "수정용 비밀 코드(매장 PIN)" 같은 간단한 접근 제한을 추가하는 방안을 제안해 줘.

## 5. 진행 순서

1. 프로젝트 스캐폴딩(Vite + React + Tailwind) 생성, 의존성 설치
2. `convenience-shift-scheduler.jsx` 의 UI/기능을 컴포넌트로 옮기기 (window.storage 부분 제거)
3. Supabase 클라이언트 연동 + 위 테이블 기준 CRUD 구현
4. Realtime 구독으로 실시간 동기화
5. 로컬에서 `npm run dev` 로 동작 확인
6. Supabase 설정 안내(프로젝트 만들기, 테이블 SQL, 키 복사)
7. Vercel 배포 안내(깃 연결 또는 CLI), 환경변수 등록, 최종 URL 확인
8. 폰에서 링크 테스트 체크리스트 제공

먼저 1~2단계까지 만들고, 중간중간 내가 확인할 수 있게 멈춰서 설명해 줘.
